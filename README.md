# MySQL复习工具

一个面向 MySQL 学习者的 AI 复习工具。从自己的笔记、课件和图片中归纳核心知识，再用一问一答的方式练习并保存学习进度。

## 下载 Windows 试用版

**[前往最新版本下载](https://github.com/xaod2271/xiaoding-review/releases/latest)**

在 Assets 中下载 `XiaodingReview-Windows-x64-0.2.1.zip`（约 11 MB）。不要下载 GitHub 自动生成的 Source code 压缩包作为安装包。

适用 Windows 10/11 的 Intel / AMD 64 位电脑。包含运行环境，无需另装 Python、Node.js 或 MySQL。当前版本尚未完成 Windows 实机验收，建议先试用。

## 开始使用

1. 右键 ZIP，选择“全部解压”。
2. 双击“启动复习室.cmd”，在默认浏览器中打开工具。
3. 在“连接设置”填写自己的 DeepSeek API Key，保存并测试连接。
4. 在“资料库”上传 MySQL 笔记、HTML 课件、XMind 或 PNG/JPEG/WebP 图片。
5. 等待 AI 整理完成，选择“不超纲”或“允许拓展”，开始复习。

## 功能

- 原始资料保留，知识点可追溯出处。
- AI 归纳核心内容，合并重复知识，并复核准确性及资料依据。
- 默认只考资料范围；开启拓展后，可学习资料外的相关知识。
- 语法、选择、翻译、概念和改错等题型，配合 AI 点评与复习进度。
- 支持备份、桌面快捷方式和同一 Wi-Fi 手机访问。

## 数据与费用

发行包从空资料库开始，不包含作者的资料、成绩、密钥或访问码。资料与进度保存在当前 Windows 用户的 `%LOCALAPPDATA%\XiaodingReview`，更新程序时保留该目录。

AI 识别、归纳、出题和点评需要网络及自己的 DeepSeek API 额度，相应资料内容会发送至 DeepSeek。密钥保存在本机配置文件，不进入网页响应或学习数据库备份。AI 结果仍需结合原资料核对。

关闭浏览器不会退出后台。请在“连接设置 → 程序与学习数据 → 退出复习室”退出。手机共享需先退出，再双击“手机共享.cmd”；默认启动仅供本机访问。
